# Homebrew Tap

Casks for apps by [Thesimpleex](https://github.com/Thesimpleex).

## Steno

Free, open-source dictation and meeting notes for macOS – [github.com/Thesimpleex/steno](https://github.com/Thesimpleex/steno)

```sh
brew install --cask thesimpleex/tap/steno
```

Steno is not notarized by Apple, so macOS blocks the first launch. Open **System Settings › Privacy & Security** and
click **Open Anyway**. See the [Steno README](https://github.com/Thesimpleex/steno#install) for details.
